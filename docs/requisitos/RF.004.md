# RF.004 - Registro e Consulta de Avistamentos de Pets Perdidos

**COMO** Membro da Comunidade ou Resgatista,  
**QUERO** registrar um avistamento com local e data/hora onde vi um animal com características de desaparecido  
**PARA** ajudar o tutor a encontrar a localização mais recente do seu pet.

---

### Critérios de Aceitação:

1. **Campos Obrigatórios**: O avistamento deve conter **Local/Ponto de Referência**, **Data/Hora**, **Descrição/Condição** e o identificador do **Pet** correspondente.
2. **Validação de Status do Pet**: Só é permitido registrar avistamentos para animais que estejam com status `PERDIDO`.
3. **Consulta de Histórico**: O sistema deve permitir consultar todo o histórico cronológico de avistamentos de um determinado pet.
4. **Notificação**: Ao registrar um avistamento, o sistema deve disparar uma notificação/log informando que novas coordenadas foram registradas.
